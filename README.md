## What is Madium?

Madium is a lightweight, free, and completely **keyless** Roblox script executor.  
It lets you attach to a running Roblox client, paste Luau scripts, and execute them with high compatibility.

- **Current version**: 1.7.3 (October 21, 2026)
- **Developer**: [pkopevs](https://github.com/pkopevs)
- **UNC score**: ~98%
- **No key system**, no ads, no premium tier

## Quick Start (Windows)

1. Download the latest build from [madium.org/download](https://madium.org/download/)
2. Extract the ZIP
3. Launch Roblox and join any experience
4. Open Madium → click **Attach**
5. Paste your script and hit **Execute**

Full installation guides for every platform are available on the official site.
