# Getting Started with Madium

## 1. Download

Go to the **only official** download page:

→ [https://madium.org/download/](https://madium.org/download/)

Choose the correct file for your platform.

## 2. Install

### Windows
1. Extract `Madium-win-x64.zip`
2. (Optional) Add the folder to Windows Defender exclusions
3. Launch Roblox first and join a game
4. Run Madium and click **Attach**

### Android
1. Enable “Install from unknown sources”
2. Install the `.apk`
3. Open Roblox → open Madium → Attach

### iOS
Requires a sideloading tool (Sideloadly, AltStore, TrollStore, etc.)

### macOS
Open the `.dmg` and drag the app to Applications.

## 3. Execute Scripts

1. Make sure the attach indicator is green
2. Paste your Luau script into the editor
3. Click **Execute** (or press the hotkey)

---

**Tip**: Always close Roblox completely before updating Madium.
