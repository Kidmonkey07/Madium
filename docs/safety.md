# Safety & Trust

## Official Domain Only

The **only** official website is:

**https://madium.org**

Any other site, Discord link, YouTube description, or “Madium Premium” is almost certainly a fake.

## Real File Names

Legitimate builds use these exact names:

- `Madium-win-x64.zip`
- `Madium-macos-universal.dmg`
- `madium-android-arm64.apk`
- `madium-ios.ipa`

Anything named `setup.exe`, `crack`, `premium`, `keygen`, or similar is malware.

## Antivirus Warnings

Executors are commonly flagged as:

- HackTool
- PUP / RiskWare
- Generic heuristic detections

This is normal.  
A **named Trojan family** with many detections usually means the file is fake.

## Recommendations

1. Download only from madium.org
2. Scan the file on VirusTotal yourself
3. Keep your Roblox account recovery options ready
4. Never run executors on accounts you care about
